# SEA4BLUE — materiale per l'esercitazione

## Avvio

1. Decomprimere `Sea4Blue.zip`.
2. Aprire `Sea4Blue.Rproj` in RStudio.
3. Aprire `analysis_guided.R`.
4. Eseguire una sezione alla volta con `Ctrl+Enter`.

Non usare `source("analysis_guided.R")` durante la lezione: controlli, oggetti intermedi e domande sono parte dell'esercitazione.

## File

- `phyloseq.rds`: oggetto con tabella ASV, tassonomia e metadata;
- `mycolors.rds`: palette conservata dal materiale originale;
- `analysis_guided.R`: script revisionato per gli studenti;
- `instructor_notes.md`: note sulle principali modifiche statistiche;
- `Sea4Blue.Rproj`: progetto RStudio con working directory riproducibile.

Il protocollo commentato è disponibile anche nella pagina **Biostatistica** del sito del corso.
